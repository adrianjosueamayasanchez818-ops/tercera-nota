crea un programa de un cajero automatico que comienza con un saldo de $100.000 y muestre este menú:
1. Ver saldo
2. Retirar
3. Depositar
4. Salir
El programa debe repetirse hasta que el usuario seleccione 4.

Reglas:
1. No permitir retirar más dinero del saldo.
2. No permitir depósitos negativos.
3. Mostrar el saldo después de retirar o depositar.
